**问：** 在今天的实验中，哪一次让 AI 编写代码时结果不符合预期？回看你当时输入的提示词，缺少了哪一项要素（角色/目标/约束/验收标准）？后来你如何补齐的？

**答：** 第一次写提示词的时候，漏掉了验收标准这一项，生成出来的代码只有摆动动画，没有要求里的摆球发光效果。后来我对照实验要求，把视觉约束和验收标准补充进提示词，重新生成代码，达到预期效果。

### 2. 闭环控制反思
**问：** 当遇到报错或动画停滞时，你是如何定位问题的？AI 提出的修复方案中，你是否看懂了它是如何通过修改物理公式或边界条件解决的？
